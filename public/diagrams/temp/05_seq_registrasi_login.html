Alur Pendaftaran Akun Tamu dan Login Pengguna / Administrator

sequenceDiagram autonumber actor Tamu as Tamu / Pengguna participant View as View (Blade) participant AuthCtrl as AuthController participant User as Model User participant Session as Laravel Session rect rgb(240, 248, 255) note over Tamu, User: Alur Registrasi Akun Baru Tamu->>View: Buka halaman pendaftaran (/register) View-->>Tamu: Tampilkan formulir registrasi Tamu->>AuthCtrl: POST /register (name, email, phone, password) AuthCtrl->>AuthCtrl: Validasi input data AuthCtrl->>User: create([name, email, phone, password, role=tamu]) User-->>AuthCtrl: User baru tersimpan AuthCtrl->>Session: Auth::login($user) AuthCtrl-->>Tamu: Redirect ke /tamu/dashboard end rect rgb(255, 250, 240) note over Tamu, User: Alur Login Pengguna Tamu->>View: Buka halaman login (/login) View-->>Tamu: Tampilkan formulir login Tamu->>AuthCtrl: POST /login (email, password) AuthCtrl->>AuthCtrl: Auth::attempt(credentials) alt Kredensial Valid AuthCtrl->>User: Cek role pengguna alt Role == admin AuthCtrl-->>Tamu: Redirect ke route(admin.dashboard) else Role == tamu AuthCtrl-->>Tamu: Redirect ke route(tamu.dashboard) end else Kredensial Salah AuthCtrl-->>View: Kembalikan withErrors View-->>Tamu: Tampilkan pesan gagal login end end
