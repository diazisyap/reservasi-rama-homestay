Alur Pembaruan Status Reservasi (Pending -> Confirmed / Completed / Cancelled)

sequenceDiagram autonumber actor Admin as Admin participant View as View (admin.reservations) participant ResCtrl as ReservationController participant ResModel as Model Reservation Admin->>View: Buka daftar reservasi (/admin/reservations) View->>ResCtrl: GET index() ResCtrl->>ResModel: with([user, room])->latest()->get() ResModel-->>ResCtrl: Data seluruh reservasi ResCtrl-->>View: Tampilkan tabel reservasi & filter status Admin->>View: Pilih aksi ubah status (misal: Confirmed) View->>ResCtrl: POST /admin/reservations/{id}/status ResCtrl->>ResCtrl: Validasi input status baru alt Status diubah ke Confirmed dan belum paid_at ResCtrl->>ResModel: update([status=confirmed, paid_at=now()]) else ResCtrl->>ResModel: update([status=status_baru]) end ResModel-->>ResCtrl: Berhasil diperbarui ResCtrl-->>View: Kembalikan notifikasi sukses pembaruan
