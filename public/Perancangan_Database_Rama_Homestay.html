PERANCANGAN BASIS DATA (DATABASE DESIGN)
SISTEM INFORMASI RESERVASI RAMA HOMESTAY
Tabel 1. Struktur Tabel users (Data Pengguna)
Fungsi: Menyimpan data autentikasi login, kredensial, dan hak akses pengguna (Admin dan Tamu).
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. id bigint unsigned - Primary Key, Auto Increment ID unik akun pengguna.
2. name Varchar 255 - Nama lengkap pengguna / tamu.
3. email Varchar 255 Unique Alamat email (digunakan untuk login).
4. phone Varchar 255 Nullable Nomor telepon / WhatsApp pengguna.
5. email_verified_at timestamp - Nullable Waktu verifikasi email pengguna.
6. password Varchar 255 - Kata sandi terenkripsi (Hash/Bcrypt).
7. role Enum 'admin', 'tamu' Default: 'tamu' Peran pengguna ('admin' atau 'tamu').
8. remember_token Varchar 100 Nullable Token untuk sesi remember me.
9. created_at timestamp - Nullable Waktu pendaftaran akun dibuat.
10. updated_at timestamp - Nullable Waktu pembaruan akun terakhir.
Tabel 2. Struktur Tabel rooms (Katalog Kamar)
Fungsi: Menyimpan data katalog kamar homestay, harga sewa, fasilitas, dan ketersediaan unit.
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. id bigint unsigned - Primary Key, Auto Increment ID unik kamar homestay.
2. name Varchar 255 - Nama kamar (contoh: Kamar 1, Kamar 2).
3. type Varchar 255 Default: 'standard' Tipe / kategori kamar homestay.
4. description Text - Nullable Deskripsi detail suasana dan kamar.
5. price Decimal 12,2 - Harga sewa per malam (Rupiah).
6. tax_rate Decimal 5,2 Default: 10.00 Tarif pajak kamar dalam persen.
7. service_rate Decimal 5,2 Default: 5.00 Tarif biaya layanan kamar dalam persen.
8. is_active Tinyint / Boolean 1 Default: 1 (True) Status aktif kamar (1 = aktif, 0 = nonaktif).
9. total_rooms Integer 11 Default: 1 Jumlah ketersediaan unit fisik kamar.
10. capacity Integer 11 Default: 2 Kapasitas maksimal jumlah tamu.
11. facilities Longtext / JSON - Nullable Daftar fasilitas kamar format JSON.
12. image Varchar 255 Nullable Jalur berkas foto utama kamar.
13. gallery Longtext / JSON - Nullable Daftar foto galeri format JSON.
14. created_at timestamp - Nullable Waktu data kamar ditambahkan.
15. updated_at timestamp - Nullable Waktu data kamar diperbarui.
Tabel 3. Struktur Tabel reservations (Transaksi Pemesanan Kamar)
Fungsi: Menyimpan data pemesanan kamar, pembayaran Midtrans/Cash, batas pembatalan 24 jam, dan pengembalian dana.
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. id bigint unsigned - Primary Key, Auto Increment ID unik transaksi reservasi.
2. booking_code Varchar 255 Unique, Nullable Kode bukti e-tiket (RMA-20261102-XXXX).
3. user_id bigint unsigned - Foreign Key (users.id) ID akun pengguna yang memesan.
4. guest_name Varchar 255 Nullable Nama lengkap tamu pemesan kamar.
5. guest_email Varchar 255 Nullable Email tamu untuk konfirmasi e-tiket.
6. guest_phone Varchar 255 Nullable Nomor telepon / WhatsApp tamu.
7. room_id bigint unsigned - Foreign Key (rooms.id) ID kamar yang dipesan.
8. check_in Date - - Tanggal mulai menginap (check-in).
9. check_out Date - - Tanggal selesai menginap (check-out).
10. total_price Decimal 12,2 - Total tagihan akhir pemesanan.
11. payment_method Varchar 255 Nullable Metode bayar (Midtrans / Cash).
12. snap_token Varchar 255 Nullable Token Snap Midtrans Payment Gateway.
13. midtrans_transaction_id Varchar 255 Nullable ID nomor transaksi resmi Midtrans.
14. midtrans_payment_type Varchar 255 Nullable Tipe metode bayar Midtrans (qris, va).
15. tax_amount Decimal 12,2 Default: 0.00 Total nominal pajak transaksi.
16. service_amount Decimal 12,2 Default: 0.00 Total nominal biaya layanan.
17. base_price Decimal 12,2 Default: 0.00 Harga dasar kamar per malam saat booking.
18. nights Integer 11 Default: 1 Jumlah durasi malam menginap.
19. guest_count Integer 11 Default: 1 Jumlah tamu yang menginap.
20. special_requests Text - Nullable Catatan / permintaan khusus tamu.
21. status Enum 'pending', 'confirmed', 'cancelled', 'completed' Default: 'pending' Status: pending (tunggu bayar), confirmed (lunas), cancelled (batal), completed (selesai).
22. paid_at timestamp - Nullable Waktu saat pembayaran berhasil/lunas.
23. expires_at timestamp - Nullable Batas waktu pembayaran (hold 30 menit).
24. cancelled_at timestamp - Nullable Waktu saat dibatalkan (maksimal 24 jam).
25. refund_note Text - Nullable Catatan garansi pengembalian dana 100%.
26. created_at timestamp - Nullable Waktu saat reservasi pertama dibuat.
27. updated_at timestamp - Nullable Waktu saat reservasi terakhir diperbarui.
Tabel 4. Struktur Tabel testimonials (Ulasan & Rating Tamu)
Fungsi: Menyimpan ulasan pengalaman menginap tamu, penilaian rating bintang, dan status moderasi.
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. id bigint unsigned - Primary Key, Auto Increment ID unik data testimoni ulasan.
2. user_id bigint unsigned - Foreign Key (users.id) ID akun pengguna yang mengulas.
3. reservation_id bigint unsigned - Foreign Key (reservations.id), Nullable ID reservasi terkait yang diulas.
4. guest_name Varchar 255 - Nama tamu yang tampil di kartu ulasan.
5. guest_origin Varchar 255 Nullable Asal kota/daerah tamu.
6. rating Tinyint 4 Default: 5 Skor bintang ulasan (skala 1 - 5).
7. review Text - - Isi pesan ulasan pengalaman menginap.
8. is_approved Tinyint / Boolean 1 Default: 0 Status persetujuan moderasi (1=aktif, 0=pending).
9. created_at timestamp - Nullable Waktu saat ulasan pertama dikirimkan.
10. updated_at timestamp - Nullable Waktu saat ulasan terakhir diperbarui.
Tabel 5. Struktur Tabel password_reset_tokens (Token Reset Kata Sandi)
Fungsi: Menyimpan token verifikasi sementara saat pengguna meminta pemulihan / reset kata sandi.
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. email Varchar 255 Primary Key Alamat email akun peminta reset password.
2. token Varchar 255 - Token acak keamanan validasi reset password.
3. created_at timestamp - Nullable Waktu saat token reset password dibuat.
Tabel 6. Struktur Tabel sessions (Sesi Login Pengguna)
Fungsi: Menyimpan data sesi aktif login pengguna pada peramban web (*browser*).
No Nama Field Tipe Data Panjang/ Ukuran Keterangan Deskripsi
1. id Varchar 255 Primary Key ID unik string sesi peramban pengguna.
2. user_id bigint unsigned - Foreign Key (users.id), Nullable ID pengguna yang sedang aktif login.
3. ip_address Varchar 45 Nullable Alamat IP perangkat pengguna (IPv4 / IPv6).
4. user_agent Text - Nullable Informasi browser dan OS perangkat tamu.
5. payload Longtext - - Data sesi terenkripsi (status login & CSRF).
6. last_activity Integer 11 - Waktu aktivitas terakhir pengguna (Unix Time).
